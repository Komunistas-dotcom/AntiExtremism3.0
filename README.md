# Сборщик реестра

Первая часть проекта: превращает официальный список экстремистских материалов
в компактный файл базы данных, по которому потом идёт проверка.

Программа проверки будет просто читать этот файл. Благодаря такому разделению
обновление списка **не требует пересборки самой программы** — достаточно
заменить один файл базы.

## Что нужно

Только Python 3.11 или новее. Никаких сторонних библиотек ставить не надо —
это сделано намеренно, чтобы потом собрать один `.exe` без установки.

## Как пользоваться

Скачайте список с сайта Министерства информации и укажите путь к файлу:

```
python -m registry.build spisok.doc -o data/registry.db
```

Поддерживаются `.doc`, `.docx`, `.odt`, `.rtf`, `.html`, `.md`. Формат
определяется по содержимому файла, а не по расширению — с сайта нередко
приходит файл с расширением `.doc`, который на самом деле `.docx`.

Посмотреть, что получилось, не создавая файл базы:

```
python -m registry.build spisok.doc --stats-only
```

Проверить, что всё работает правильно:

```
python -m unittest discover -s tests -t .
```

## Про исправление написаний

Главная опасность для такой программы — **ложное «у вас чисто»**. Она возникает,
когда адрес в реестре записан с кириллическими буквами, неотличимыми от
латинских: `vk.соm`, `оk.ru`, `chаnnel`, `раra2022`. Глазом они выглядят
нормально, но для компьютера это другая строка, и совпадение молча теряется.

Сборщик разбирает такие случаи по-разному в зависимости от места:

- **В доменном имени** кириллица недопустима по стандарту, поэтому исправляется
  всегда — включая буквы вроде `к`, которые в остальных местах трогать нельзя.
- **В имени аккаунта** решение зависит от написания. Смешанное (`раra2022`)
  исправляется на латиницу. Целиком кириллическое (`ОбществоГомель`) —
  настоящее название, оно не трогается.
- Когда однозначно решить нельзя (`НАША` кириллицей + `MOBA` латиницей),
  в базу заносятся **оба** варианта: лишняя запись в индексе безвредна,
  а пропущенное совпадение — нет.

Кроме того, исправляются опечатки составителей реестра, найденные сверкой всех
доменов списка с названиями площадок: `twiter.com`, `yotube.com`, `facebok.com`,
`instgram.com`, `tiktok.eom`, `treads.com` и другие.

## Что намеренно не попадает в базу

- **Отменённые решения** — 9 записей. В самом реестре у них уже вычищено
  содержимое, остаётся только слово «Отменено» и реквизиты. Запись сохраняется
  с пометкой, но никаких признаков для проверки с неё не берётся.
- **Домены-посредники** — `apps.apple.com`, `archive.is`, `bit.ly` и подобные.
  Они есть в истории браузера почти у каждого, и как признак дали бы
  ложное срабатывание. Конкретная ссылка внутри такого домена при этом
  сохраняется.
- **Имена аккаунтов, похожие на домен** (`baj.media.by` в Instagram) — не
  дублируются ещё и как отдельный сайт.

## Строение

| Файл | Назначение |
|---|---|
| `registry/ingest.py` | чтение исходного файла любого формата |
| `registry/confusables.py` | таблицы похожих букв и правила их замены |
| `registry/normalize.py` | приведение адресов к единому виду |
| `registry/parse.py` | разбор таблицы реестра на записи |
| `registry/build.py` | запись снапшота в SQLite |

Все находки, на которых построены правила (какие опечатки встречаются, где
кириллица, сколько адресов заканчивается точкой), получены разбором реального
файла, а не предположениями. Тесты закрепляют каждый такой случай.

## Известное ограничение

Разбор двоичного `.doc` (старый формат Word 97-2003) выполняется через
LibreOffice и **на реальном файле министерства пока не проверялся** — в среде
разработки LibreOffice оказался нерабочим, а сайт министерства недоступен.
Формат `.docx` разбирается напрямую и проверен тестами. Если сборщик на
настоящем файле выдаст ошибку, самый быстрый обходной путь — открыть файл в
Word или LibreOffice и сохранить как `.docx` или `.html`.
